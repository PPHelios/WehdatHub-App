# WehdatHub App

Mobile app for WehdatHub brokers (Android and iOS), built with bare React Native.

- `apps/mobile` - the app
- `packages/shared` - code shared with the future website (brand colours, formatting, later the API client and input rules)

Checks: `pnpm typecheck`, `pnpm lint`, `pnpm test`. CI also builds an Android debug APK and an iOS simulator build on every pull request.
